# Windows 新号训练任务运行器

> 状态：已根据 2026-07-28 的完整录像完成离线标定和任务代码；尚未在目标 Windows/Apex 中做真实输入验收。

## 目标与入口

该任务面向 `2560×1440`、中文、全屏的新账号，从当前已知页面继续推进，完成训练场后回到大厅，并把模式明确切到“未上榜（三人赛）”。它不处理 EA 密码或验证码；检测到登录/双重验证页会暂停，用户完成后自动恢复。

Windows `cmd.exe` 中最短的验证方式：

```bat
validate-tutorial.cmd
start-tutorial.cmd
```

等价的 PowerShell 包装命令：

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 validate tutorial
powershell -NoProfile -ExecutionPolicy Bypass -File .\run.ps1 start tutorial
```

`start tutorial` 不倒计时。终端或浏览器在前台时任务只显示等待；切回 Apex 后才允许发输入。`F8` 仍是紧急停止，本地控制台仍位于 `http://127.0.0.1:8765`。

## 实际流程

```text
继续页
  → EA 登录/验证码（只识别，人工完成）
  → 已知欢迎/纪念页（正向 OCR 后 Esc）
  → 训练大厅“准备”
  → 移动 / 疾跑 / 跳跃 / 下蹲
  → 小步跑向补给箱
  → 开箱 / 捡枪和弹药
  → 武器说明 / 射空 / 捡轻型弹药 / 换弹
  → 副武器
  → 注射器 / 小型护盾电池 / 治疗菜单
  → 位置 / 敌人 / 武器 / 弹药 / 标记菜单
  → 退出训练并确认返回大厅
  → 可选的账户 / 好友 / 设置 / 进度导览
  → 打开模式面板
  → 明确选择“未上榜（三人赛）”
  → 匹配大厅“准备”可用，任务目标完成
```

训练场动作不是一条定时宏。每一步都先连续两次识别中文任务清单或视觉锚点，再执行一个有限动作，随后等待配置中列出的后置状态。短暂加载或提示切换不会丢掉待确认动作；错误后置状态不会被当作成功。动作达到上限后进入可恢复暂停，并继续观察画面，不会退出进程或无限盲试。

训练结束存在两条已支持分支：

- 录像中的新分支：账户 → 好友 → 设置 → 进度 → 选择模式；
- 昨天的旧分支：没有导览，直接到匹配大厅。

导览期间底部也会显示“选择”，所以程序不会只靠按钮图判断。四张导览页由完整中文语义区分；只有导览消失后，“选择 + 训练 + 射击场”同时成立才允许打开模式面板。

## 清障与未知画面

任务内的确定步骤使用 `windows/config/tutorial-states.zh-CN.json`。它只负责把画面路由到候选状态，不能单独授权输入；动作及允许后置状态位于 `windows/config/first-tutorial-2560x1440.zh-CN.json`。

升级、奖励和公告仍走独立的安全清障字典。教程入口会自动武装这些已声明的 `Enter`/`Esc` 规则。计划外页面若两套字典都不认识，会释放输入、保存未知截图并进入低频观察；页面变化后可自行恢复。它不会对未知页面点击鼠标，也没有启用 AI 猜测。

普通观察约每 300ms 一次；教程 OCR 最多约每 900ms 发起一次，并要求连续两次命中。普通帧不落盘，只有状态变化、障碍和未知证据保存在 `windows/runs/<时间>/screenshots/`。

## 离线验证范围

当前离线样本覆盖：训练大厅、全部主要中文任务清单、两个教学说明页、训练完成、退出菜单、退出确认、四张大厅导览、模式选择页和最终匹配大厅。验证命令同时检查模板互斥性和 OCR 路由。

离线验证只能证明“录像帧能被正确识别、决策配置能装载”，不能证明目标 Windows 会接受 `SendInput`，也不能证明录像推断出的镜头位移一次通过。

第一轮真实验收最可能需要微调的是：

- 从坡道跑到补给箱的单次前进时长；
- 副武器/治疗物品前是否保持在可交互准星；
- 最后一组敌人、武器和弹药标记的相对鼠标位移。

这些动作均有尝试上限和后置确认。若停住，请不要人工把任务终端关掉；先从本地控制台看 `observedState`、`pauseReason` 和最近截图，再按需暂停或停止，并保留该次 `windows/runs/<时间>/`。

## 明确不在本轮范围

- 自动填写 EA 账号、密码或验证码；
- 通用三维导航、目标检测或任意地图寻路；
- 公共匹配中的战斗、近战、倒地爬行和自动下一局；
- AI 视觉兜底和反作弊绕过。
