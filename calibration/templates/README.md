# 2560x1440 zh-CN templates

这些模板来自同一组 `2560x1440`、中文、全屏 PNG，只包含稳定的按钮或 HUD 区域：

- `continue.png`：启动页“继续”；
- `lobby-ready.png`：新手任务完成后的“准备”；
- `legend-select.png`：英雄选择页左上角模式标签；
- `following-detach.png`：历史文件名；实际原图显示“是跳伞指挥官”，当前用于等待 `E 发射`，不会按 `LCTRL`；
- `launch-ready.png`：可自主跳伞时的 `E 发射`；
- `freefall-speed.png`：自由落体速度尺；
- `landed-ability.png`、`landed-weapons.png`：落地后的地面 HUD。

模板坐标、阈值与稳定帧数定义在 `windows/config/first-match-2560x1440.zh-CN.json`。
